# V1.20 — Histogram Threshold Segmenter

## Goal

Add a histogram-driven intensity threshold segmentation pipeline to the General
Analysis tab. The tool identifies image regions by intensity (dark, bright,
band-pass, etc.), is stain-agnostic, operates across the full bit-depth range
(default 12-bit, 0–4095), and produces a boolean mask + int32 instance labels
compatible with the existing `AnalysisResult` contract. It is designed to be a
drop-in exclusion-mask producer alongside `TearDetectionPipeline` and
`NucleiSegmentationPipeline`.

## Approach

Build the core logic as a Qt-free subpackage at
`nd2studios/backend/analysis/histothresh/` (seven modules). Register it into
the existing `AnalysisPipeline` registry via a thin adapter
(`histogram_threshold_pipeline.py`). Add a force-import in `__main__.py`. The
Analysis page requires no changes — it auto-discovers registered pipelines via
`AnalysisPipeline.get_pipelines()`.

No standalone package, CLI, napari plugin, Pydantic, or HTML reporting.

## Files Created

### `nd2studios/backend/analysis/histothresh/`

| Module | Responsibility |
|--------|----------------|
| `__init__.py` | Re-exports `HistogramThresholdSegmenter`, `SegmentationResult`, `ThresholdConfig` |
| `validation.py` | `validate_bit_depth()` — rejects float dtype, unsupported depths, and values overflowing the declared max (strict=True raises; strict=False warns). `infer_bit_depth()` for fallback. |
| `histogram.py` | `Histogram` dataclass (counts, bin_edges, bit_depth, total_pixels) with `percentile()` / `cumulative()`. `compute_histogram()` bins the full LUT range — one bin per integer value. Four `suggest_threshold_*()` helpers (Otsu, Triangle, Minimum, Multi-Otsu) using scikit-image histogram API. |
| `thresholds.py` | `threshold_single()` (below/above/between/outside), `threshold_hysteresis()` (inverts image for `below` to reuse scikit-image's high-pass hysteresis), `threshold_percentile()` (with optional sanity_floor/ceiling clipping), `threshold_relative()` (fraction of within-frame median). |
| `morphology.py` | `apply_spatial_constraints()` — opening → closing → hole-fill → small-object removal. `homogeneity_gate()` — local-std gate (disabled by default). |
| `config.py` | `ThresholdConfig` plain dataclass. `__post_init__` validates that method/direction combinations have the required parameters. No Pydantic. |
| `identifier.py` | `HistogramThresholdSegmenter.run(image, *, reference_mask, voxel_size)` — single 2-D frame. Returns `SegmentationResult` (mask, int32 labels, regions list-of-dicts, histogram, threshold_used, provenance). |

### `nd2studios/backend/analysis/histogram_threshold_pipeline.py`

`HistogramThresholdPipeline` registered via `@AnalysisPipeline.register`.
- `get_params()`: 16 `ParamSpec` entries shown in the Analysis tab form.
- `run()`: loops T frames, calls `HistogramThresholdSegmenter.run(frame)`,
  stacks (T,H,W) int32 label arrays, builds `AnalysisResult`.
- `_build_config()`: maps param dict → `ThresholdConfig`, passing only the
  params relevant to the chosen method (avoids triggering `__post_init__`
  validation on unused fields). Sets `bit_depth_strict=False` so TIFF inputs
  that overflow the declared range warn rather than crash.

## Key Decisions

1. **Pydantic → dataclass.** `ThresholdConfig` uses `@dataclass` with
   `__post_init__` validation. Pydantic is not in ND2Studios' dependencies.

2. **Per-frame segmentation.** `identifier.py` operates on a single 2-D frame.
   The pipeline adapter loops over T, mirroring `TearDetectionPipeline`. This
   avoids accumulating the entire (T,H,W) stack in RAM during segmentation.

3. **`bit_depth_strict=False` in pipeline.** TIFF inputs often overflow the
   declared bit depth after upstream processing. The pipeline issues a warning
   rather than crashing; strict mode remains available via direct API use.

4. **Hysteresis `below` uses image inversion.** scikit-image's
   `apply_hysteresis_threshold` is a high-pass operator. For `below`, we invert
   the image so that dark pixels become high-valued, apply the high-pass
   hysteresis, and return the result. The `strict ≤ permissive` invariant for
   `below` is validated before inversion.

5. **No pandas in `identifier.py`.** `regionprops_table` returns a dict of
   arrays; we convert to `list[dict]` directly. Pandas is only used in the
   pipeline adapter's `_build_summary()` (via numpy aggregation over lists).
   This keeps the core subpackage dependency-minimal.
