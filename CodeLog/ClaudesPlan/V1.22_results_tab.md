# Plan: Results Tab (V1.22)

## Goal
Add a "📊 Results" tab that takes the `AnalysisResult` label masks produced by
the Analysis page, computes an extended per-object measurement table, and lets
the user export CSV / overlay images / label-mask TIFFs.

## Motivation
The Analysis page already produces label masks and a basic measurements list,
but only exposes mean_intensity and area. Researchers need richer morphological
descriptors, per-channel intensity stats, and — most importantly — centroid
positions in absolute stage coordinates (µm) so objects can be relocated on the
microscope.

## Approach

### Backend: `results_engine.py`
Pure logic, no Qt.  Uses `skimage.measure.regionprops` (existing dependency).

`compute_measurements(label_masks, channels, metadata, m_index)`:
- Iterates segmentation channels × T frames
- Calls `regionprops(mask_frame, intensity_image=primary_img)`
- Adds per-channel mean/std from masked pixels of every channel array
- Computes absolute stage coordinates as:
  `stage_x + (centroid_x_px - W/2) × pixel_size_um`
  where `stage_x` comes from `metadata["stage_xy_um"][m_index]` (already
  present in `nd2_metadata` for ND2 files; skipped when absent)

`export_overlay_frames(channels, label_masks, metadata, output_dir, fmt)`:
- Builds uint8 RGB composite from channel arrays + channel_display LUT settings
- Burns in combined binary mask as semi-transparent cyan overlay
- Writes per-frame files as TIFF or JPG via `imageio`

`export_label_masks_tiff(label_masks, output_dir)`:
- Writes each `(T,H,W)` int32 mask stack as an ImageJ-compatible TIFF via
  `tifffile`

### UI: `results_page.py`
- Pipeline selector populated from `exp.analysis_results` keys
- "Compute Measurements" button runs `compute_measurements()` synchronously
  (measurements are fast; no worker needed)
- Sortable `QTableView` backed by `_MeasurementsModel(QAbstractTableModel)`
  + `QSortFilterProxyModel`
- Summary panel: static labels for n_objects / n_frames / mean+std area_um²,
  dynamic rows for per-channel mean intensity
- Export row: CSV, Label Masks TIFF, Overlay Images (format combo: TIFF / JPG)
- Empty-state label when no analysis has been run

### State management
- `exp.results_config` (`{"pipeline": str, "image_format": str}`) persists
  the active pipeline selection and image format choice through session save/load
- `results_config` added to `ND2StudiosRecord.to_dict()` serialization

## Key decisions
- **Synchronous compute**: measurements are fast (regionprops on already-loaded
  arrays); no worker thread needed for the Results tab itself
- **Stage coordinates**: extracted from `metadata["stage_xy_um"][m_index]` which
  is already present in `nd2_metadata` from `read_nd2_metadata_extended`; no
  new field needed on the record
- **ND2 export not supported**: the `nd2` library is read-only; TIFF and JPG
  cover the imaging output use case
