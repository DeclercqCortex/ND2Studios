# V1.2 — Collapsible LUT sidebar + corner tile-layout preview

**Date:** 2026-04-30
**Author:** Gabriel Declercq (with Claude)
**Status:** in progress
**Branch:** Version-1.2

## Goal

Make the viewer breathe.

1. Move the per-channel LUT histograms from the row-under-image to a
   collapsible right sidebar. The image canvas gets the vertical space
   back. A header button collapses / expands the sidebar with the same
   `QPropertyAnimation` (InOutQuart, 280 ms) we already use for the
   main app sidebar.
2. Add a small tile-layout thumbnail overlay in the bottom-right
   corner of the image when M > 1. It shows every M position drawn at
   its stage XY, highlights the currently displayed tile, and serves
   as a click-to-stitch shortcut.

## Non-Goals (intentional)

- No multi-channel TIFF input support (still V2 candidate).
- No autosave.
- No live overlap blending in the stitch (still V1.2+ candidate after
  this UX work lands).
- No tile preview on the Recipe page — that page already operates on
  the user-chosen M, so the multi-tile inset would be misleading.

## Approach

### Layout restructure for `MultiAxisViewer`

Old V1.1 layout (vertical stack):

```
ImageCanvas
zoom_row
M / T / Z sliders
ChannelControlRow (toggle + color + LUT) × N
```

New V1.2 layout (horizontal split with collapsible right column):

```
QHBoxLayout (root)
├── Left column (stretch=1)
│     ImageCanvas        ← TilePreviewWidget overlay (bottom-right)
│     zoom_row
│     M / T / Z sliders
│     ChannelChip strip  (compact: ☑ name [color combo] × N)
└── Right column (collapsible, fixed width 260 when expanded)
      Header row (title + collapse button)
      QScrollArea
        LutHistogramWidget × N (each labelled with channel + color swatch)
```

`ChannelChip` is a new widget with just an enable checkbox and a color
combo — the bits the user clicks frequently. The histograms move out
of the way into the sidebar.

The sidebar collapse/expand uses the same animation pattern as
`MainWindow._toggle_sidebar` so the UX feels consistent: animate
`minimumWidth` *and* `maximumWidth` to keep `QHBoxLayout` from
fighting the animation.

### Tile-layout preview

A new `TilePreviewWidget` (`widgets/tile_preview.py`) that:

- Takes `stage_xy_um`, `pixel_size_um`, `tile_h`, `tile_w`,
  `m_indices`, and `current_m`.
- Reuses `compute_tile_layout()` from
  `backend/exporters/stitch_exporter` to figure out where to draw the
  tile rectangles (so the preview matches the actual stitch result).
- Paints with `QPainter` (rectangles + a small "Stitch…" caption).
  Faster than embedding a matplotlib canvas and free of layout fights.
- Highlights the currently displayed M in `ACCENT_PURPLE`.
- Emits `stitch_requested` on click; the Import page wires this to
  `_on_stitch()` so the existing dialog opens.
- Auto-shown by `MultiAxisViewer` only when M > 1 *and* the volume
  has stage XY positions. Otherwise it stays hidden — there's nothing
  to preview.

The widget is parented onto the `ImageCanvas` (not the viewer's outer
layout) and positioned absolutely in the bottom-right corner with an
8 px margin. `MultiAxisViewer.resizeEvent` repositions it.

### Data flow additions

`MultiAxisViewer.set_volume()` gains an optional
`stage_xy_um: List[Tuple[float, float]]` parameter. The Import page
already has these — they live in `nd2_metadata['stage_xy_um']`.

No data-model changes. No new fields on `ND2StudiosRecord`.

## Key Decisions

1. **`QPainter`-rendered tile preview, not `MplCanvas`.** Matplotlib
   for a 160×120 px static thumbnail is overkill; rectangles drawn
   directly are 100× cheaper and don't trigger axis re-layout on
   every M change.
2. **Chip strip stays under the image.** Toggle and color are
   one-click operations; we don't bury them in a sidebar that might be
   collapsed. The sidebar holds only the LUTs (the deliberate
   contrast-tuning controls).
3. **Sidebar collapses by changing widths, not visibility.** This
   keeps the layout stable — toggling a `setVisible` would cause Qt
   to recompute the whole `QHBoxLayout` and produce a flicker. We
   animate `minimumWidth`/`maximumWidth` from 260 to 0 and back.
4. **Click on tile preview → `StitchDialog`.** Free UX win; saves the
   user from hunting for the "Stitch M…" button.
5. **No tile preview on Recipe page.** Recipe operates on the chosen
   M; showing all tiles there would be confusing and irrelevant.

## Validation

- `py_compile` clean across all new + modified files.
- AST import-resolution check (every `nd2studios.*` import resolves).
- Manual GUI test on a real multi-position ND2:
  - Tile preview appears in the bottom-right corner with the right
    arrangement; current tile is highlighted; clicking opens the
    stitch dialog.
  - LUT sidebar collapses smoothly; image canvas takes the freed
    width; expanding restores all LUT widgets and their state.
  - Channel chip strip toggles channels live; LUT widgets recompose
    on drag.
