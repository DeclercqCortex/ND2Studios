# V1.24 — Background Mask Overlay for Bright / Dark Spots

**Target version:** V1.24
**Owner:** Claude Code
**Parent feature:** Bright / Dark Spots pipeline (V1.21)

---

## Goal

Extend the Bright / Dark Spots pipeline with an optional secondary binary mask overlay that
covers every pixel **not** detected as a bright or dark spot. This "background mask" lets the
user visually evaluate background signal levels in the same frame as the spot overlay, and adds
per-frame background intensity statistics to the exported measurements CSV.

---

## Approach

Minimal, additive change across four files:

1. **`spots/config.py`** — add `background_mask: bool = False` field to `SpotsConfig`.
2. **`spots/identifier.py`** — add `background_labels: np.ndarray | None = None` field to
   `SpotsResult`; compute it as `(~(labels > 0)).astype(np.int32)` when
   `cfg.background_mask` is True (done at the end of `run()`, before provenance stamping).
3. **`core/analysis_registry.py`** — add three new fields to `AnalysisResult`:
   - `secondary_label_masks: Dict[str, np.ndarray]` — keyed overlays rendered after the
     primary spots mask.
   - `secondary_overlay_color: Optional[tuple]` — single (R, G, B) color for all secondary
     masks; defaults to `(160, 160, 160)` (neutral gray for background).
   - `secondary_overlay_alpha: float = 0.3` — blend weight (lighter than the spots overlay).
4. **`backend/analysis/spots_pipeline.py`** — in `BrightDarkSpotsPipeline`:
   - New `ParamSpec("background_mask", "Background mask", "bool", False)`.
   - Read flag, pass to `SpotsConfig`.
   - Accumulate `bg_stack` per-frame when enabled.
   - Compute `background_mean_intensity` and `background_std_intensity` per frame (mean/std
     of raw pixel values over the background region) and append to each measurement row so
     they appear in the CSV export.
   - Populate `AnalysisResult.secondary_label_masks` and set secondary color/alpha.
5. **`pages/analysis_page.py`** — update `_composite_overlay` to iterate
   `result.secondary_label_masks` and composite each secondary mask on top of the primary
   overlay, using `result.secondary_overlay_color` and `result.secondary_overlay_alpha`.

---

## Key decisions

- **Inverse mask is always binary** (single label value = 1). Multi-label background is
  meaningless here; a solid color overlay is what the user wants.
- **Gray (#A0A0A0, alpha 0.25)** for the background so it reads as "fill" without drowning
  the underlying image or competing with the spot color (blue, alpha 0.80).
- **`secondary_label_masks` on `AnalysisResult`** rather than a pipeline-specific side
  channel: makes the rendering logic in `analysis_page.py` generic. Any future pipeline can
  produce secondary overlays without further changes to the page.
- Background intensity stats go into the **per-spot measurement rows** (same frame), not into
  a separate background-row list, so the CSV stays in a single flat table. Every spot row for
  a frame carries the same `background_mean_intensity` / `background_std_intensity` values.
