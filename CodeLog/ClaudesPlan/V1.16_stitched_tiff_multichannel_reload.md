# V1.16 — Stitched TIFF Multi-Channel Reload

## Goal

Fix re-import of stitched multi-channel TIFFs exported by ND2Studios. Previously,
all channels appeared on the T slider because the TIFF loader ignored ImageJ metadata
and treated every TIFF as a single-channel `(T, H, W)` series.

## Approach

The stitch exporter already writes a correct `(T, Z=1, C, H, W)` TIFF with
`imagej=True` and channel names in `metadata={"Labels": ch_names}`. The fix is
entirely on the **load side**:

1. Read ImageJ metadata with `tifffile.TiffFile.imagej_metadata` to recover
   `n_t`, `n_z`, `n_c`, and `channel_names`.
2. For each channel, build a `LazyTIFFChannel` that computes page indices with
   `page = t * n_z * n_c + page_within_t` (where `page_within_t = c_idx`
   for the Z=1 stitched case).
3. Return the proper `{channel_name: LazyTIFFChannel}` dict from `LoadWorker`.

## Files Modified

- `nd2studios/backend/tiff_loader.py`
  - `LazyTIFFChannel.__init__`: added `n_pages_per_t`, `page_within_t` params
  - `LazyTIFFChannel._read_frame`: page index formula updated
  - `LazyTIFFChannel.crop`: copies new attributes
  - Added `read_imagej_tiff_metadata(filepath) -> dict`
  - Added `load_imagej_tiff_channels(filepath, ij_info, ...) -> Dict[str, LazyTIFFChannel]`

- `nd2studios/workers/load_worker.py`
  - `_load_tiff()`: calls `read_imagej_tiff_metadata` first; branches on `n_channels > 1`
    to use multi-channel path; also propagates `pixel_size_um` from TIFF tags

## Key Decisions

- **Default params preserve backward compatibility.** All existing callers of
  `LazyTIFFChannel(...)` and `load_tiff_stack_lazy(...)` work unchanged.
- **No eager load.** Large stitched TIFFs (potentially many GB) are still accessed
  lazily frame-by-frame via `tifffile.imread(..., key=page)`.
- **stitch_exporter.py untouched.** The export format `(T, Z=1, C, H, W)` with
  `imagej=True` is correct and backward-compatible with Fiji/ImageJ.
- **pixel_size_um** from the TIFF `XResolution` tag is now propagated through
  the metadata dict so the viewer can show correct scale information.
