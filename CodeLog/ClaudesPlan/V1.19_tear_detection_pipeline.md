# V1.19 — Tear / Dark Region Detection Pipeline

## Goal

Implement the classical Phase-1 baseline from `tear_region_analysis_build_guide.md`
as a new `AnalysisPipeline` registered in the existing General Analysis tab.

No new GUI pages, no DL dependencies. The pipeline drops into the existing
`AnalysisPipeline` framework and the Analysis tab auto-discovers it.

## Problem

Fluorescence microscopy slides often have physical tears, bubbles, or
off-section areas that produce artifactual dark, spatially homogeneous regions.
These regions must be identified so downstream quantification (cell counts,
intensities) can exclude them. The build guide specifies a multi-phase roadmap;
this plan covers Phase 1 only (classical baseline).

## Approach

A four-stage pipeline, all in `nd2studios/backend/analysis/tear_detection.py`:

### Stage 1 — Tissue mask
Otsu threshold on log-intensity at 4× downsample + Gaussian blur, then
morphological closing/fill/opening, upsampled back to full resolution.
Downsampling speeds up the operation and smooths sensor noise before
thresholding.

### Stage 2 — Homogeneity score map
Per pixel inside the tissue mask:
- `local_intensity` = `uniform_filter(norm_frame, win)`
- `local_variance`  = `generic_filter(norm_frame, np.var, win)`
- `local_entropy`   = `skimage.filters.rank.entropy(uint8_frame, disk(win//2))`

All three rank-normalised to [0,1] within the tissue mask
(rank normalization = robustness against batch-to-batch intensity drift).

`score = (1 − norm_I) × (1 − norm_V) × (1 − norm_E)`

### Stage 3 — Region extraction
Threshold score map + tissue mask → connected components (skimage).
Filter by `min_area_um2` / `max_area_um2`. Compute `regionprops`:
area, centroid, eccentricity, solidity, mean_intensity.

### Stage 4 — Classification
If a counterstain channel is provided:
- `tissue_floor` = 15th-percentile of counterstain signal inside tissue mask
- Region is `weak_stain` if `mean_counterstain > tissue_floor`, else `tear`
Without counterstain: class = `unknown`.

## Key Decisions

1. **Rank normalization throughout.** The single most important robustness
   choice per the build guide. Absolute intensity thresholds break across
   batches, acquisitions, and microscopes.

2. **Phase 1 only.** nnU-Net, SAM, PatchCore, and 3D extension are Phase 3+.
   The classical baseline is genuinely competitive when annotated data is
   scarce and ships without any optional ML dependency.

3. **Plug into existing Analysis tab.** No new page needed. The tab's
   generic pipeline runner, param editor, worker, preview, and export
   buttons all work unchanged.

4. **Dynamic CSV fieldnames** in `analysis_page.py`. Changed the hardcoded
   7-field list to `list(measurements[0].keys())` so all pipelines export
   their full measurement dicts without per-pipeline page changes.

5. **`counterstain_channel` injection** added to `analysis_page._load_params()`
   alongside the existing `channel_name` injection.
