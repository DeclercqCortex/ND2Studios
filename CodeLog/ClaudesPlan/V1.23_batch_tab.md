# Plan: Batch Tab (V1.23)

## Goal
Add a "⚡ Batch" tab that loads a saved `.nd2st.json` pipeline template,
processes a user-selected folder or file list through the full pipeline
(load → recipe → analysis → measurements), and writes a single aggregate
CSV with all per-object results plus a `source_file` column.

## Motivation
Users want to run the same pipeline over many ND2 files and get a unified
measurement table without manually repeating the Import → Recipe → Analysis →
Results steps for each file.

## Approach

### Template format: `backend/template.py`
`.nd2st.json` (extension constant `TEMPLATE_EXTENSION`):
```json
{
  "nd2s_template_version": "1.0",
  "name": "My Pipeline",
  "created": "ISO timestamp",
  "pipeline": {
    "import": { "z_mode": "max", "frame_stride": 1 },
    "recipe": [{"name": "GaussianBlur", "params": {"sigma": 1.0}}],
    "recipe_normalized": false,
    "analysis": { "pipeline_name": "HistogramThreshold", "params": {} },
    "results": { "image_format": "tiff" }
  }
}
```
`save_template()` builds the dict from experiment fields.
`write_template()` serialises to disk (adds extension if missing).
`load_template()` validates version and returns the dict.

### Worker: `workers/batch_worker.py`
`BatchWorker(BaseWorker)` with extra signal `file_done(int, int)`.

Per-file sequence (all within the worker thread, no nested QThreads):
1. `LoadWorker(filepath, ...).run_task()` — reads file, builds lazy channels
2. Materialise all lazy channel proxies into contiguous numpy arrays
3. `RecipeWorker(channels, recipe, normalized).run_task()` if recipe non-empty
4. `pipeline.run(channels, metadata, params, ...)` using the registered
   `AnalysisPipeline` class looked up by name
5. `results_engine.compute_measurements(label_masks, channels, metadata)`
6. Append `source_file = os.path.basename(filepath)` to every row
7. Optionally call `results_engine.export_overlay_frames()` into
   `<output_dir>/<basename>/`

Per-file errors are caught and logged to `status` signal without aborting.
After all files: write `batch_results.csv` with `source_file` as first column.

### UI: `pages/batch_page.py`
Three main groups:
- **Template**: path + browse + "Save current session as template" (opens
  `_simple_text_input` dialog for name, then `QFileDialog.getSaveFileName`)
- **Files**: `QListWidget` (duplicate-safe via `data(Qt.UserRole)`),
  Add Files / Add Folder (auto-scans .nd2/.tif/.tiff) / Clear / Remove Selected
- **Output**: directory picker, export-images checkbox + format combo (TIFF/JPG)
- **Run row**: Run Batch / Cancel, progress bar, status label

On `finished`: offers to open output folder via `os.startfile` / `xdg-open`.

### State management
`exp.batch_config` stores `template_path`, `output_dir`, `image_format`,
`export_images`; round-trips through `.nd2s` session save/load.

## Key decisions
- **Sequential not parallel**: each file is processed one at a time to avoid
  OOM on large datasets and to keep progress reporting simple
- **Synchronous worker calls**: `LoadWorker.run_task()` / `RecipeWorker.run_task()`
  / `pipeline.run()` called directly (not via `.start()`) since we're already
  in a background thread
- **Error isolation**: try/except per file so one bad file does not abort the batch
- **Template version field**: `"nd2s_template_version": "1.0"` in the JSON so
  future format changes can raise a clear error rather than silently misparse

## Verification
1. Run full pipeline on one file (Import → Recipe → Analysis → Results)
2. Go to Batch → Save current session as template → give it a name
3. Load the saved template, verify name + created date shown
4. Add 2–3 ND2/TIFF files; verify file count updates
5. Set output directory; click Run Batch
6. Watch progress bar advance per file; verify status messages
7. When done, open `batch_results.csv` — confirm `source_file` first column,
   row counts match sum of per-file object counts
8. Enable export images; re-run; confirm `<output_dir>/<basename>/frame_*.tiff`
   appear with cyan mask overlay
