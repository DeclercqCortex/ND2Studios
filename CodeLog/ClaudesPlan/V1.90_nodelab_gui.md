# V1.90 — NodeLab: standalone Pipelines GUI on `pipeline_kit`

## Goal

Build a new **Blender-style node editor** (NodeLab) for the ND2Studios
Pipelines system, in a standalone project (`ND2Studios_Blender`), consuming the
`pipeline_kit` backend through its public API — **without modifying the backend**
(parity must stay green). Deliver the full editor + Run + save/load, with a
clean seam for the interactive special-node handlers.

## Key decisions (resolved)

1. **Framework / paradigm** — PySide6 `QGraphicsView`/`QGraphicsScene`; keep the
   node-graph paradigm. Monochrome + one configurable accent (`#6FE3FF`).
2. **Backend delivery — vendored copy.** Copy the whole `nd2studios/` package in
   (≈4 MB), preserving the `nd2studios.pipeline_kit` import path so internal
   imports are unchanged and the copy is **byte-for-byte identical** (parity
   holds). The full palette registers (analysis/method nodes register by
   importing their `nd2studios.backend.*` engines at import time) and enhancement
   recipes execute for real. `ND2STUDIOS_ROOT` overrides to an external checkout.
3. **Special-node handlers — GUI-agnostic seam (option a, scoped).** Instead of
   lifting ~3k lines out of `pages/pipelines_page.py`, NodeLab defines a registry
   keyed by `op_key` (`nodelab/run/handlers.py`). Pure-compute paths run for
   real; interactive nodes are simulated until a real handler is registered.

## Approach / files

- **Scaffold** — `run.py`, `nodelab/app.py`, `bootstrap.py`, `theme.py`,
  `nodelab.qss` (accent-templated), `specs.py`, `glyphs.py`.
- **Canvas** — `canvas/view.py` (pan/zoom/grid/fit + mouse interaction),
  `scene.py` (model-bound; connect / splice / selection), `node_item.py`,
  `socket_item.py`, `edge_item.py`.
- **Panels** — `panels/palette_panel.py` (registry-driven, searchable, drag),
  `properties_panel.py` (from `ParamSpec`, `visible_when`), `results_panel.py`,
  `viewport_panel.py`.
- **Chrome** — `chrome/menu_bar.py`, `toolbar.py`, `console_dock.py`,
  `status_bar.py`.
- **Run** — `run/controller.py`, `worker.py` (QThread, off-UI), `handlers.py`
  (seam). Drives `GraphRunner`; `apply_recipe` for enhancement; branch pruning
  for if-else.
- **Assembly** — `main_window.py` wires every signal to scene / run / io.

## Hard contracts honored

- Backend untouched → `_pipeline_kit_parity.py --check` = no drift.
- `op_key`s frozen; save/load via `pipeline_kit.io` (`.nd2s_pipeline.json`, v6).
- Data shapes `(T,H,W)`; long work off the UI thread in a `QThread` worker.

## Verification

- Offscreen boot of the full window (grabbed to PNG for fidelity review).
- Interaction logic tests: connect rules, one-wire, cycle rejection, splice.
- Run end-to-end (real enhancement compute + simulated actions + branch).
- Save/load round-trip (schema 6 preserved).
- `_pipeline_kit_parity.py --check` + `_pipeline_graph_selftest.py` green vs the
  vendored copy. `py_compile` across all `nodelab` modules.

## Not in this pass (extension points)

  register into the seam.
- Real TIFF loading into the viewport / Run input (synthetic volume for now).
- Loop back-edges, condition-block editor, per-edge scope/view-only levers UI.
