## 0. Scope

Turn the Phase-1 headless core into a lazy, tiled, memoized data engine:
a **provider** (`Dataset.image.get_tile`), a **two-hash memo**, **revision-stamped**
immutable layers, **tree-reducible** lattice reductions, **whole-frame** structure
compute, and a recording **ReadContext** for calibration. Qt-free; the viewer (QRhi)
is a separate consumer.

## 3. The provider contract — now `(m,t,z,c,y,x)`

```python
# nodegraph/provider.py
class TileProvider(Protocol):
    axes: AxisSizes                      # includes c
    levels: int                          # multiscale count (0 = full res)
    def get_tile(self, level: int, m: int, t: int, z: int, c: int,
                 iy: int, ix: int) -> np.ndarray: ...   # one (block_y, block_x) tile
    def get_region(self, level, m, t, z, c, y0, y1, x0, x1) -> np.ndarray: ...
```
- `Dataset.image` holds a `TileProvider` (the reserved slot).
- **b2nd provider:** block = tile; `get_tile` slices the `.b2nd` array → decompresses only
  the touched block(s). **Coarse-for-viewing is a SEPARATE pyramid** — b2nd has no MIP layer
  (§J correction); build downsampled levels at ingest (per-domain reducer: mean for intensity,
  **nearest/mode for labels**).
- **nd2 provider (pre-ingest preview):** `to_dask()` materialize-while-open (note: `read_frame`
  **segfaults** on the sample — use the dask path, as the benchmark does); memoized at *plane*
  granularity only.

## 4. `AttributeLayer` amendment — revision + **safe** immutability

Per §I.b, but honoring the §J aliasing catch (`np.asarray` returns the caller's array; freezing
its `writeable` flag mutates the producer's buffer or raises on a non-owning view). **Copy-or-own
before freezing.**

```python
# nodegraph/dataset.py
@dataclass(frozen=True)
class AttributeLayer:
    domain: Domain
    name: str
    values: np.ndarray
    layer: Optional[str] = None
    revision: int = field(default_factory=next_revision)   # content identity (never id())

    def __post_init__(self):
        a = np.asarray(self.values)
        if a.flags.writeable and (a.base is not None or a is self.values):
            a = a.copy()                      # own the buffer before freezing (§J fix)
        a.flags.writeable = False
        object.__setattr__(self, "values", a)

    def mutate(self, new_values) -> "AttributeLayer":
        return replace(self, values=new_values, revision=next_revision())
```
`revision` is the memo identity; `Dataset.with_attribute` already structural-shares via `replace`,
so a new layer carries a fresh revision and any key referencing the old revision auto-invalidates.

## 5. Reducers → associative monoids (tree-reduce / halo)

Per §I.d, with the §J correction that **`first` IS tile-reducible** (global-first is in the first tile).

```python
# nodegraph/reducers.py
class PartialReducer(Protocol):
    associative: bool
    def lift(self, tile, axes): ...          # tile -> partial
    def combine(self, p, q): ...             # partial ⊕ partial (associative)
    def lower(self, p): ...                   # partial -> final
MEAN = (sum,count)->div;  SUM/MAX/MIN/COUNT self-combine;  FIRST = positional (tileable);
MEDIAN = non-associative -> falls back to a whole-domain realization (§7b)
```
- **Pure lattice axis-fold needs NO halo.** A **halo** (radius-wide ghost border) is only for
  stencil ops (gradient, EDT, morphology) a downstream field/watershed consumes.
- A cancelled tile pull drops its partial without corrupting the fold.

## 6. Two-hash memo + revision fence (the core invariant)

```
recipe_hash  (LOOKUP, pre-compute, PROXY — never pixels):
   leaf   = blake3(file_id, byte_offset, mtime_ns, dtype, shape, (m,t,z,c), reader_params)
   node   = blake3(op_key, params, sorted(declared_reads), tuple(upstream recipe_hashes),
                   tuple(upstream layer.revision))
output_fingerprint (CUTOFF/DEDUP, post-compute, CONTENT):
   = blake3(payload.tobytes())  # per-tile for images; full for KB-MB structure tables
pull(node): rh=recipe_hash; if rh in memo: return memo[rh]
            payload=compute(); fp=output_fingerprint(payload)
            if fp==prev_fp(node): mark_backdated   # downstream early-out (Salsa cutoff)
            memo[rh]=Entry(blob[fp], fp, next_revision())
```
Cross-cutting invariant (§I): **memo identity is a cheap monotonic revision + declared inputs —
never Python `id()`, never an 85 MB content read.** This is the *restated* "content-hash memo."

## 7. Structure domains — whole-domain compute + seeded watershed → Arrow

- Mark CCL/watershed nodes `Granularity.WHOLE_PLANE` (2D) or `WHOLE_VOLUME` (3D): realize the full label array **once**,
  memoize as one **proxy-keyed** payload; the viewer's `get_tile` on a LABEL layer **slices**
  the finished array (numpy view, no recompute).
- **Track/Label id stability:** use id-carrying **seeded watershed** — `watershed(-edt, markers=
  point_ids, mask=fg)` so each label id *is* the tracked seed id, stable across the Timepoint axis;
  never tile-local renumber. (No GPU watershed exists — cuCIM #89 — so this stays CPU.)
- Per-element attributes live in **Arrow RecordBatch** tables (Label/Point/Track), CSR connectivity
  as `ListArray`; hashed by cheap **full** content hash (§H.4).
- Benchmark the whole-frame CCL/watershed cost on a real 6554² plane before trusting "compute-once
  is affordable" (§J: `cc3d 0.27 s/512³` does **not** transfer to 6554² anisotropic).

## 7b. Node data-access footprint — the granularity taxonomy (amended per the package survey)

The §I `Granularity` enum (`TILEABLE` | `WHOLE_FRAME`) is **too coarse**. The image-processing
package survey ([node_backend_reference.md](../Architecture/node_backend_reference.md)) shows the
real node families need a richer *data-access footprint* — which axes a node must consume **whole**
vs per-element. The scheduler/memo must know this per node (it generalizes the old
`AnalysisPipeline.needs_full_stack` flag):

```python
class Granularity(Enum):
    TILEABLE     = "tileable"      # pointwise / small-stencil 2D — honors the tile provider
                                   #   (threshold, gamma, per-tile filter)
    WHOLE_PLANE  = "whole_plane"   # needs a full (Y,X) plane per (m,t,z,c)
                                   #   (CCL, watershed, 2D wavelet/starlet, phase-corr shift)
    WHOLE_VOLUME = "whole_volume"  # needs a full (Z,Y,X) volume per (m,t,c)
                                   #   (3D deconvolution, 3D TV/wavelet, 3D registration warp)
    WHOLE_SERIES = "whole_series"  # needs the full T series per (m,c)
                                   #   (drift/temporal registration, stacking/fusion, tracking)
    MULTI_VIEW   = "multi_view"    # needs several M (tile stitching, multi-view fusion)
```

Two consequences for the engine:

1. **The footprint gates tiling, halo, and memo granularity.** `TILEABLE` streams through the tile
   provider; `WHOLE_PLANE`/`WHOLE_VOLUME`/`WHOLE_SERIES`/`MULTI_VIEW` are realized whole (once) and
   memoized as a single proxy-keyed payload; their raster output may then be *sliced* per display
   tile. Halos apply only to `TILEABLE` stencil ops.
2. **Some nodes change `AxisSizes`.** Stacking reduces T→1; stitching/fusion reduces M→1 and grows
   Y,X; crop/resample change spatial extent. Such a node returns a **new `Dataset` with new
   `AxisSizes`** (Phase-1 `Dataset` already carries its own axes, so this is allowed) — but the memo
   entry, provider, and downstream tiling key off the *output* geometry, and the transform it
   estimates (e.g. a per-frame registration matrix) is stored as a **Frame-domain attribute**.

**True-3D vs stack-of-2D is a first-class node attribute**, matching the survey's central
distinction: a node declares `WHOLE_VOLUME` (genuine (Z,Y,X)) vs `WHOLE_PLANE` looped over Z
(stack-of-2D). The catalog must not silently treat one as the other (the `skimage denoise_wavelet`
3D caveat is exactly this trap).

## 8. `ReadContext` — declared calibration reads (§I.e)

Nodes never touch `Dataset.metadata` directly; every read goes through a recording `ReadContext`
whose `(key, value_digest)` set folds into the node's `recipe_hash`. Guard `metadata` against
un-contexted reads (debug-mode `Mapping` proxy) so a hidden calibration read is a hard error, not a
silent stale hit.

## 9. Field memo namespace (§I.f)

Fields are unevaluated expression trees with **one** materialization site (Halide `compute_at`),
keyed `("field", field_expr_hash, domain, token)` in a namespace **disjoint** from the image tile key
`(recipe_hash, tile_id)`: `token = tile_id` for image-coupled fields, `domain_version` for
element-domain fields (structure domains never tiled). `field_expr_hash` reuses layer **revisions**
(§4) + declared reads (§8). Constant/broadcast fields realize to a non-materializing `VirtualArray`.

## 10. Viewer note (QRhi) — honor the §J texture cap

The GPU viewer is **QRhiWidget** (PySide6 6.7+; Metal/D3D/Vulkan/GL). **Do not** assume a 6554²
plane is "one texture": QRhi's OpenGL/GLES fallback guarantees only **2048–4096** max dimension
(6554 > 4096), so query `maxTextureSize()` at runtime and tile the display texture when it exceeds
the cap. CPU `QGraphicsScene` tiled path remains the baseline; QRhi only if it can't hold 60 fps.
