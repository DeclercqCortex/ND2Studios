# V1.0 — Initial Scaffold

**Date:** 2026-04-30
**Author:** Gabriel Declercq (with Claude)
**Status:** in progress

## Goal

Stand up the ND2Studios application end-to-end at minimum-viable scope so that
a lab user can:

1. Browse for an ND2 (or TIFF) file from disk.
2. See full metadata (T/Z/C/P sizes, pixel size, z step, channel names,
   exposures, timestamps, stage XY/Z, objective, binning).
3. Pick which channels to enable, assign each a color, set Z-projection mode.
4. Build a linear processing recipe by trial → accept (or reject) → repeat.
5. Save and load recipes as portable `.nd2s_recipe.json` files.
6. Export the result as:
   - A Z-projection TIFF stack (per channel, max / mean / min)
   - An RGB composite TIFF stack
   - A time-lapse movie (MP4 / GIF) with scale bar, timestamps, and channel
     overlays
7. Save and load full sessions as `.nd2s` files (resume-where-you-left-off).

## Non-Goals (intentional)

- No cell segmentation. No StarDist. No TensorFlow.
- No cell tracking. No Hungarian / SerialTrack.
- No spatial-field analysis (divergence, curl, density maps).
- No headless / HPC mode (the scaffolding is present but not wired up).
- No theme switching. Dark only.

If you need any of those, use CellTracker — that's what it's for.

## Approach

### Architecture

We mirror CellTracker's proven layout but trim it to ND2Studios scope:

```
core/         page-orchestration + state
widgets/      reusable Qt widgets (Qt-aware)
backend/      pure Python — no Qt imports
plugins/      registered enhancement plugins (decorator-based)
workers/      QThread workers with progress/finished/error signals
pages/        the three GUI pages
```

This separation makes the backend trivially testable and (later) trivially
runnable headlessly.

### Reuse from CellTracker

We are a **sibling**, so we copy rather than depend:

- `backend/nd2_loader.py` — verbatim. The `LazyND2Channel` proxy and
  `ND2Metadata` dataclass are already excellent.
- `plugins/enhancement/builtin.py` — verbatim, all 19 plugins.
- `widgets/image_viewer.py`, `widgets/scale_bar.py`,
  `widgets/video_player.py`, `widgets/common.py` — verbatim or near-verbatim.
- `core/plugin_registry.py` — verbatim.
- `workers/base_worker.py`, `workers/load_worker.py`,
  `workers/enhance_worker.py`, `workers/export_worker.py` — adapted.
- `core/experiment_manager.py` — adapted: drop `_label_stack`,
  `_measurements_df`, `_tracked_df`. Add explicit `recipe` and
  `export_config`. Session extension `.nd2s` instead of `.cta`.

### Net-new for ND2Studios

- `core/settings.py` — Dracula palette (Modern_GUI_PyDracula's exact RGB
  values), our 3-page list, custom title bar dimensions, animation duration.
- `core/theme.py` — QSS adapted from PyDracula's `py_dracula_dark.qss`,
  plus widget-specific rules ported from CellTracker.
- `core/main_window.py` — net-new. Implements PyDracula's animated
  collapsible sidebar (60 ↔ 240 px, `QPropertyAnimation` with
  `InOutQuart` easing) and frameless title bar with `CustomGrip` resize
  handles. Manages the `QStackedWidget` page stack and routes nav clicks.
- `widgets/custom_grips.py` — ported from PyDracula, lets the frameless
  window resize at the edges.
- `backend/exporters/tiff_exporter.py` — single-channel TIFF stack writer
  (uint8 / uint16, BigTIFF when needed).
- `backend/exporters/composite_exporter.py` — multi-channel RGB TIFF
  with per-channel LUTs.
- `backend/exporters/movie_exporter.py` — `imageio` MP4 / GIF writer with
  optional scale bar overlay, optional timestamp overlay (drawn via PIL),
  and per-channel color compositing.
- `pages/import_page.py` — file browse, metadata table, channel rows
  (enable + color), Z-projection selector, preview area.
- `pages/recipe_page.py` — plugin picker, parameter editor, trial / accept
  / reject buttons, save/load recipe JSON, before/after preview.
- `pages/export_page.py` — three sub-tabs (TIFF / Composite / Movie) with
  the per-export options that make sense for each.

### Page state machine

The status ladder simplifies to:

```
new → imported → preprocessed → ready_to_export
```

Navigation guards:
- `recipe` requires `imported`
- `export` requires `imported` (recipe is optional — you can export the
  raw file straight to a movie if you want)

### Data flow

```
File on disk
   │
   │  ImportPage → LoadWorker
   ▼
ExperimentRecord._raw_channels  (Dict[str, LazyND2Channel])
   │
   │  RecipePage → RecipeWorker
   ▼
ExperimentRecord._processed_channels  (Dict[str, np.ndarray])
   │
   │  ExportPage → ExportWorker
   ▼
.tiff / .mp4 / .gif on disk
```

## Key Decisions

1. **Sibling, not fork.** Backend code is duplicated. We pay a small
   maintenance tax in exchange for clean independence. Revisit if more than
   ~30% of the backend ends up shared.
2. **Page count = 3.** Import / Recipe / Export. More pages can be added in
   V1.1+ without touching the navigation infrastructure.
3. **Navigation guards stay loose.** The user can jump to Export at any
   time after Import; recipe steps are optional.
4. **No autosave in V1.0.** CellTracker's autosave existed because
   detection takes minutes. Our pipeline is fast enough that explicit
   Save / Load is sufficient. Revisit if recipe runs become slow.
5. **Movie export uses `imageio` (FFmpeg).** Avoids OpenCV's spotty
   video-encoding licensing situation. `imageio-ffmpeg` is a drop-in
   binary.
6. **Channel colors in compositing match CellTracker's `CHANNEL_COLORS`
   palette** so users get a consistent look across both apps.

## Validation / Verification

- `python3 -c "import nd2studios.__main__"` must succeed without errors.
- `python3 -c "import nd2studios.core.main_window"` must succeed.
- `python3 -c "import nd2studios.plugins.enhancement.builtin"` must
  succeed (this loads + registers all plugins via the decorator).
- Manual test on a real ND2: open it, scroll metadata, render a preview,
  apply CLAHE, export a max-Z TIFF.

## Open questions

  the Export page.
- Should the timestamp overlay use ND2 acquisition timestamps (per-frame)
  or a synthetic `t = frame_index * dt` with user-supplied dt? Proposing
  ND2 timestamps when available, fall back to synthetic with dt set from
  the Import page.
